Course Objectives

To bridge the gap between MAS and AI techniques. AI techniques can be used for programming more flexible agent architecture and problem solving abilities. MAS itself can be used for problem solving and computer-aided decision making.

Training

  1. AI Techniques for MAS:
    • agent architecture
    • action planning
    • control strategies
    • adaptative control & learning
  2. MAS for problem solving:
    • problem solving techniques
    • MAS problem-solving
    • Design methodologies
